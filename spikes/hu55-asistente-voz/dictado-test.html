HU-55 — Captura cruda de dictado

Herramienta descartable para el spike del asistente de voz. Usa Web Speech API (lang=es-AR, continuous, interimResults) y muestra la transcripción tal cual la devuelve el motor, sin ningún procesamiento propio. Objetivo: ver cómo maneja "coma", "punto", números en palabras y qué puntuación inserta sola.

Frases sugeridas para probar: "grasa tres coma seis, proteína tres punto dos, acidez catorce", "grasa tres con seis", "grasa tres sesenta", "acidez catorce coma cinco".
Si al tocar Iniciar no pide permiso de micrófono o tira error not-allowed, este archivo abierto como file:// puede estar siendo bloqueado — probá servirlo con npx serve . (o similar) y abrirlo por http://localhost.

Este navegador no soporta SpeechRecognition/webkitSpeechRecognition. Abrí este archivo en Chrome de escritorio.
